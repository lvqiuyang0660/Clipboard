# 剪贴板助手（ClipboardHelper）

Windows 上的轻量剪贴板历史工具：随手复制的东西自动留存，随时呼出搜索、置顶、收藏，
并能在**两台电脑之间加密同步**（局域网、共享文件夹、或自建服务器中转）。

界面用纯 WPF 手写（不用任何 UI 框架），单文件 exe，无需安装 .NET 之外的运行库。

## 主要功能

- **历史留存**：自动记录文字与图片，按天分组，支持搜索、置顶、收藏、复制次数统计。
- **浮层呼出**：快捷键唤出列表，键盘选、回车粘贴；深色 / 浅色主题跟随系统。
- **隐私优先**：疑似密码类内容（密码框、验证码等）默认不记录、也不外发；
  所有记录只存在本机，不联网上传。
- **两台电脑同步**（三种方式任选，可随时切换且不影响本地历史）：
  - **局域网直连**：同一 Wi-Fi 下自动发现，配对码确认后点对点同步。
  - **共享文件夹**：借助 OneDrive / 坚果云等同步盘交换数据，适合不常同时在线的两台电脑。
  - **自建服务器**：把密文经自己的服务器中转，适合两台电脑在不同网络下使用。
- **端到端加密**：配对时用 6 位配对码派生临时密钥交换长期密钥，
  之后所有内容帧都用 AES-256-CBC + HMAC-SHA256 加密；服务器只存密文，没有解密密钥。
- **图片按需取**：只同步"有这么一张图"的元数据，点开时才向另一台取原图。

## 构建与运行

需要 Windows + .NET Framework 4.x（系统自带），不需要 Visual Studio。

```powershell
# 在项目根目录执行，产出 dist\ClipboardHelper.exe
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

双击 `dist\ClipboardHelper.exe` 即可运行（首次运行会在用户目录下建立本地历史库）。

源码结构：

| 路径 | 说明 |
| --- | --- |
| `src/` | 客户端全部源码（WPF，C# 5 语法，单文件编译） |
| `src/Sync.cs` | 局域网 / 共享文件夹同步：发现、配对、加密通道、增量同步 |
| `src/SyncServer.cs` | 自建服务器方式：HTTP 收发密文帧、长轮询、断线重连 |
| `server/` | 自建同步服务器（Go，单文件、无数据库） |
| `docs/` | 需求方案、部署说明 |
| `ui/index.html` | UI 设计稿（浏览器直接打开可看） |

## 部署自建同步服务器

服务器只做**密文中转**：不持有明文、不存解密密钥，落盘的内容与客户端上传的一致（密文），
日志里只有连接与错误码。程序是单个 Linux x64 可执行文件，不依赖数据库。

最简单的三步（详细图文版见 [`docs/deploy-selfhost.md`](docs/deploy-selfhost.md)）：

```bash
# 1. 上传 server/ 目录到服务器，例如 /opt/clipsync，然后：
cd /opt/clipsync && sudo bash install.sh          # 默认端口 47820

# 2. 在阿里云「轻量应用服务器 → 防火墙」放行 TCP 47820

# 3. 服务器上自检
curl http://127.0.0.1:47820/v1/health             # 返回 {"ok":true,...}
```

然后在两台电脑上：设置 → 同步 → 方式选「自建服务器」→ 填公网 IP 与端口 → **测试连通** →
第一台「生成配对码」，第二台输入配对码，第一台点「允许加入」。

也支持 Docker：

```bash
cd /opt/clipsync && sudo docker compose up -d --build
```

- 端口可配置：`sudo CLIP_PORT=50000 bash install.sh`（客户端填同样的端口）。
- 地址可以填 IP，也可以填域名；HTTPS 为可选项（内容本身已端到端加密，TLS 只是额外一层）。
- 访问控制：配对码 + 已配对设备白名单、试错限流与临时封禁、过期中转数据自动清理，
  可随时查看已配对设备并吊销。
